# Marble

Personal working preferences and reusable coding workflows.

## Layout

```
memory/        working preferences and their index
observations/  general tool behavior and its index
skills/        portable workflows
codex/         global instructions and additional memory
scripts/       guarded synchronization
weekly-log/    local logs, excluded from version control
```

Read the memory and observation indexes before using a linked entry. Feedback memories
are standing instructions. Recheck observations according to their expiry rules.

The global instructions link to `codex/AGENTS.md`. On this Mac the checkout is
`/Users/alexr/Marble`. Adjust those paths when setting up another machine.
`scripts/sync.sh` synchronizes a clean `main` and refuses divergent histories.

Skills describe portable procedures. Keep outside organizations, client registries,
project records, and unrelated repository details out of this repository and its history.
Use local, untracked storage for private name registries and project logs.
