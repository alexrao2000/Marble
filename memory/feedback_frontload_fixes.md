When reporting something that was fixed, lead with the fact that it was fixed. Write "Fixed: {description}" not "{description of the problem}. Fixed by {how}."

**Why:** The user reads summaries to know what happened. Leading with the problem buries the resolution.

**How to apply:** In any summary or status update that mentions a fix, start the sentence or bullet with "Fixed:" or the equivalent active-voice lead.
