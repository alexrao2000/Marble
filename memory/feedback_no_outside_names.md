Do not mention outside organizations, companies, or repositories in replies or generated
content. Keep references generic and limited to the current task. Do not carry identifying
names, links, paths, issue numbers, code, or repository history from other work into it.

Alex explicitly asked for this after an unrelated repository name appeared. A name being
present in memory is not permission to repeat it. Public visibility alone does not override
this preference; only name an outside entity when Alex explicitly asks for it.

This applies to the repository's entire commit history as well as current files. Do not
export outside project records, account mappings, or client name registries into this
personal repository. Keep private registries and logs in local, ignored storage.
